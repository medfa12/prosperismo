# Prosperismo branding

All distributable, user-facing surfaces use **Prosperismo**:

- application and window titles;
- native executable and package names;
- logs, crash reports, profiler sessions and RenderDoc capture prefixes;
- settings directories and configuration files;
- CI artifact/release names;
- issue templates and default guest-visible host names.

The canonical icon variants live under `assets/branding`.

Historical names remain only where required for attribution or evidence:

- Kyty/KytyPS5 license notices, upstream provenance and implementation-history
  discussion;
- SharpEmu citations in migrated investigation notes and source provenance;
- exact external repository names and links;
- legacy internal identifiers whose immediate rename would create needless ABI
  or regression risk. These identifiers must not be shown to users.

This distinction is intentional. Rebranding does not erase GPL authorship or
alter the origin of recovered evidence.
