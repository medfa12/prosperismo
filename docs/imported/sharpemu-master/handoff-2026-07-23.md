## Worth stealing from KytyPS5 (github.com/KytyPS5/KytyPS5 @ 8587638) — ranked, file:line grounded
KytyPS5 is a REAL PS5/RDNA2/Vulkan emulator (not the PS4 InoriRus/Kyty). Both trees ~40-70k LOC. Our shader scalar path is a single linear-pass interpreter; theirs is a formal CFG-dataflow + symbolic-descriptor pipeline.

**Tonemap-black:**
1. **CFG reaching-definition + value-numbering provenance** — MISSING. `shader/recompiler/ScalarProvenance.cpp` (`Builder::Run`): worklist fixpoint over the block graph, per-block entry/exit `ScalarState`, inserts Phi on predecessor disagreement, hash-cons value graph. Models loop-carried/merged descriptor bases our linear walk can't. Effort L (needs our decoder to expose CFG blocks; our linear IR doesn't carry them).
2. **Symbolic SRT sources + fold-or-fail-with-PC evaluator** — the direct fix, sits on #1. `SrtWalker.cpp`/`SrtPatcher.cpp`: records each `S_BUFFER_LOAD` symbolically, const-folds offsets, **validates buffer bounds and returns a diagnostic with the exact PC on failure instead of silently yielding 0**, bakes resolved loads to flat-slot reads. Effort M-L. Highest correctness payoff per line.

**Perf-churn / VkImage growth:**
3. **Page-fault guest-memory tracker** — MISSING. `pageManager`+`memoryTracker`+`regionManager`: `VirtualProtect` guest pages, per-page cpu/gpu dirty bitmaps → untouched texture costs zero. Also closes the "UI buffer with no GPU producer" gap. Effort L (needs a host OS fault handler — the hard part).
4. **VA-keyed persistent buffer/texture caches** — PARTIAL. We persist render-target surfaces (`GuestSurfaceCache`) but sampled tex/buffers create-per-draw + full re-hash. Theirs returns same VkImage per VA, re-uploads only dirty ranges. Effort L (depends on #3).
5. **Always-on per-resource caches + fixed 8-deep command-buffer ring** — PARTIAL (ours opt-in/size-class keyed). Effort M — cheapest perf win.
6. **VMA slab sub-allocator** — PARTIAL (our `VulkanDeviceMemoryLedger` only counts bytes; each image still its own `DeviceMemory`). Effort M.
7. **GPU-compute detiler** — MISSING (we're CPU-only in `Gfx10Detiler.cs`). 9 precompiled compute kernels + push-constants. Effort M-L.
8. **RangeSet + MultiLevelPageTable substrate** — MISSING, Effort S — small pure-C# ports #3/#4 need; do first.

Sequencing: tonemap = 1→2; perf = 8→3→4 then 5/6 parallel; detile = 7 last.
**NOTE:** for NGG *amplification* specifically, KytyPS5 offers NOTHING to port — it lowers `GS_EMIT/GS_CUT` to SPIR-V no-ops (`spirvEmitterControlFlow.cpp:372`) and hard-aborts on real amplification (`shader.cpp:301`). Negative confirmation only.
