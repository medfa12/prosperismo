# Historical shell implementation ledger

The full pre-migration implementation ledger is preserved byte-for-byte at
`docs/imported/sharpemu-home/ps5-ui-state-of-work.md`.

It records useful evidence locators and rejected approaches, but it is not a
status report for the React Native application. The active migration and
validation record is [React Native shell migration](react-native-shell-migration.md).

Do not treat historical worktree paths, implementation claims, environment
variables, or rendering status in the archived ledger as current product state.
